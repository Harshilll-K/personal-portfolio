## 🔍 The Vision
The **Investigative Archive** is not just a resume; it's an immersive digital experience. Built to feel like a classified database or a terminal-based investigative interface, it prioritizes visual excellence, smooth interactivity, and a cohesive "Secure Protocol" narrative.

## 🚀 Core Features

- **Immersive 3D Hero**: Interactive particle sphere powered by **Three.js** that reacts to mouse movement and morphs dynamically.
- **Cinematic Interactivity**: Custom preloader with a HUD interface, biometric analysis simulation, and scramble text effects.
- **Fluid Navigation**: Implementation of **Lenis** for smooth-as-glass horizontal scrolling, combined with **GSAP** for scroll-triggered animations.
- **Identity Matrix**: A detailed overview of technical expertise and "extended bio" presented in a dossier-style layout.
- **Interactive Visualizations**: 3D-styled CGPA progress bars and inventory-style skill grids.
- **Secure Communication**: Fully functional contact protocol with EmailJS integration and brutalist form design.
- **Responsive Architecture**: Optimized for desktop, tablet, and mobile viewing while maintaining the cinematic integrity.

## 🛠️ Tech Stack

## 📁 Project Structure

- `index.html`: The core structure and DOM elements for the archive.
- `style.css`: The "Brutalist-Glassmorphism" design system, containing variables, animations, and responsive layouts.
- `main.js`: Orchestrates GSAP animations, Lenis scrolling, and UI interactivity.
- `hero3d.js`: Dedicated Three.js logic for the particle sphere background.
- `public/`: Static assets including images, logos, and the resume PDF.

## ⚙️ Installation & Usage

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Step-by-Step Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Harshilll-K/personal-portfolio.git
   cd personal-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
